## 1 · 现状诊断（3 条，每条一句代价）

1. **色=没选**：indigo+slate 是 Tailwind 出厂默认组合，系统正确但等于「没选」——代价：一眼像后台模板，看不出「有人正在监测你的品牌」。
2. **层=无节奏**：整页白卡灰描边，零暗块、零发光点，趋势和快照图视觉同级——代价：数字没有「信号」的聚焦感，科技感无从谈起。
3. **权=不分**：品牌靛既做动作色又做数据色（E3 已拍板，不动），且趋势主线与平台柱共用 `series.visibility` 一色——代价：「随时间变化」和「当下状态」两种信息无法靠视觉区分。

**方向**：科技感不是加一缸色，是把「监测」题材的签名动作立起来 = **时间信号台**。唯一签名动作，其余守纪律。

## 2 · 方案一：自定义时间范围（翻案项，交互形态）

- **形态**：保留 All/Day/Week/Month 分段（默认路径不动），新增 **Custom** 触发器；点击弹出浮层（`shadow-md`、`rounded-xl`，浮层是全局唯一允许阴影处），内含 From/To 两个 `<input type="date">`。
- **有界优先**：日期是有界值，不用自由文本框（来源：`patterns/af-controls-and-data-entry`）；`min=data.from`、`max=data.to`，非法值无处输入。
- **无模式**：改日期即写 URL（`from`/`to` 已存在），无 Apply 按钮；浮层外点/Esc 关闭（来源：`patterns/af-modeless-feedback`）。375 下浮层全宽堆在分段下。
- **色彩 token 草案**：零新色——浮层用 `surface-card`/`line`/`shadow-md`，日期框描边沿用 `line-strong`，焦点环沿用 `brand`。
- **图表形态**：范围作用于全页（现有架构已支持）；趋势卡降级规则沿用现有逻辑——<7 天不画滚动线、只画日值点，subtitle 注明。

```
现状 Range ──┐                方案 Range ──┐
[All|Day|Week|Month|Quarter▽]      [All|Day|Week|Month|Custom▽]
                                      └─ 浮层 ─────────┐
                                          ┌─ ─ ─ ─ ─ ─ ─ ─ ─┐
                                          │ From [2026-08-12] │
                                          │ To   [2026-08-21] │
                                          │ ✓ 行内校验 · Clear │
                                          └─ ─ ─ ─ ─ ─ ─ ─ ─┘
```

| 状态 | 分段高亮 | 触发器文案 | 行为 |
|---|---|---|---|
| 无 from/to | All | Custom | 浮层打开时为空 |
| 命中某预设 | 该预设 | Custom | 改日期即脱离预设 |
| 其余任意 | 无（Custom 激活） | `Aug 12 – Aug 21` | URL 已是该区间 |
| from > to | — | — | 行内提示「Start is after end」，URL 保持上次有效值 |
| 区间 0 题 / <7 天 | — | — | 各卡既有 empty 态 + `Clear filters`；趋势无滚动线 |

## 3 · 方案二：科技感（signal 信号族 + 趋势信号台）

- **签名动作**：趋势卡整块改为**深墨信号台**——`#0F172A` 底 + 青色滚动线 + 右上 `● LIVE` 点 + 细网格纹理（纯 CSS gradient，渲染代价≈零）。题材来源：监测台最辨识度的是「屏幕上的信号」，不是新色。
- **不踩的雷**：近黑+单酸绿（黑名单 #2）、紫蓝渐变+玻璃拟态（黑名单 #6）——青取 cyan-teal 非酸绿，暗台只此一块、其余全页保持亮底克制。
- **色彩 token 草案**（对比度实算，白 `#FFFFFF` / 页底 `#F8FAFC` / 暗台 `#0F172A`）：
  - `signal` `#0891B2` — 亮底图形 3.68 ✓；`signal-ink` `#0E7490` — 亮底文字 5.36 ✓
  - `signal-on-dark` `#22D3EE` — 暗台滚动线/文字 9.88 ✓
  - `surface-console` → 复用 `ink.DEFAULT` `#0F172A`（不新增裸值）；`ink-inverse` `#F1F5F9` 16.30 ✓；`ink-on-console` `#94A3B8` 6.96 ✓；`line-console` `#1E293B`（纹理，装饰无门禁）
  - 暗台日值点 `#64748B` 3.75 ✓（暗版例外 E2，绑 v1.1 走查）
- **图表形态**：`chartTheme.ts` 增 `geoConsole` 主题变体（暗底轴/分割线/tooltip 反相），**现有 `geo` 主题与其他图零影响**；`series.signal` 替换趋势线色。
- **失败长什么样**：若走查时被读成「开发者工具台」而非「品牌被监测」→ 退 Plan B：亮底卡 + 青线，signal 族保留、暗台 token 不落码。**已上线 MVP 页 → 问题清单先于规范**，本方案不改已拍板色值，只做增量。

## 4 · 方案三：多维趋势细分（抗噪 + 视图形态）

- **数据事实**（questions.json 实算）：日 4 题；平台粒度 19/30 天、Topic 粒度 15/30 天（每 2 天 1 题）、Intent B 15/30、**S=0**。日值在细分级不可读，必须滚动窗口。
- **交互形态**：趋势卡加 `By:` 分段 `Overall | Intent | Platform | Topic`（默认 Overall）。**联动=复用 FilterBar 全局筛选**——细分视图自动响应平台/话题/意图筛选，不建第二套点击下钻模型（一个交互模型原则）。
- **抗噪规则**：① 窗口自适应：意图 7 日（A/C 每日），平台/话题 14 日（窗口内平均 ≥1 题/日）；② 窗口 <8 题不画线，显 `Too few samples`（沿用 n<8 规则）；③ 短范围（<7 天）无滚动线只画点（现有逻辑）；④ 断点 `null` 不连线（`connectNulls:false` 现有）；⑤ S 意图 n=0 不画线，图例置灰 + 脚注「S has no monitored questions」——数据真话，不造线。
- **图表形态**：Intent = 同一信号台 3 线（A `#14B8A6` 7.17 / B `#2DD4BF` 9.59 / C `#5EEAD4` 12.07，暗台用「实感」编码，语义靠图例）；Platform/Topic = **小多图**（每维一格，统一 `#22D3EE` 线 + n 徽标，hover 高亮其余降透明度）。Table 视图沿用，空值 `—`（来源：`patterns/dense-b2b-table`）。
- **空态**：一格多题不足 → 「Too few samples」+ 无动作（筛选在 FilterBar）；全空 → 既有 empty 态 + `Clear filters`（来源：`patterns/empty-state`）。

## 5 · Token 计划（加 / 改 / 为什么）

| 动作 | token | 值 | 为什么 |
|---|---|---|---|
| 加 | `signal` / `signal-ink` | `#0891B2` / `#0E7490` | 亮底「信号」图形/文字，与品牌靛分工：靛管状态，青管时间 |
| 加 | `signal-on-dark` / `signal-subtle` | `#22D3EE` / 浅青底 | 暗台主线 / LIVE 点底（P1） |
| 加 | `surface-console`（指向 `ink.DEFAULT`） | `#0F172A` | 暗台底复用现有值，零新增裸值 |
| 加 | `ink-inverse` / `ink-on-console` / `line-console` | `#F1F5F9` / `#94A3B8` / `#1E293B` | 暗台文字/轴标签/网格纹理，全部 ≥4.5 或装饰 |
| 加 | `intent-line` A/B/C | `#14B8A6` / `#2DD4BF` / `#5EEAD4` | 暗台意图线阶梯，全部 ≥3 |
| 改 | `chartTheme.ts` 增 `geoConsole` 变体 + `series.signal` | — | 其他图零影响；趋势线换信号色 |
| 不改 | 06 全部已拍板色值（brand/cov/intent/severity…） | — | v1.1 增量版，不推翻对比度门禁 |

**为什么只加不改**：全站唯一色值源 `tokens.ts` 不动结构；语义 token 增量为 v1.1 版本号，老架落码零迁移。

## 6 · 复审：这是选择还是默认？

| 项 | 会 / 不会 | 说明 |
|---|---|---|
| 色 | 不会 | 避开两个现成「科技感」默认答案（黑名单 #2 近黑+酸绿、#6 紫蓝渐变） |
| 签名动作 | 不会 | 时间信号台来自「监测」题材；换记账/客服题材不会得到它 |
| 布局 | 不会 | 亮底克制 + 唯一暗块 = 明暗节奏，非模板卡片套件 |
