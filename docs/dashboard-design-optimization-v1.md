## 0 · 一句话结论

苏姐终审：✅ **可落码**，无 P0/P1 阻塞。三个需求最终裁定：**需求 3 方向对、形态必须改**（30 天×每天 4 行数据下多线细分是噪音制造机 → 半程×单维归因 + 有限窗口线）；**需求 1 同意翻案但带护栏**（演示可信度是真实理由）；**需求 2 是感知问题不是信任问题**（信任已由 06 语义色+对比度建立，只做一处签名动作 + 三处点缀）。

## 1 · 需求 1：自定义时间范围（P0 · 翻案必做）

- **形态**：保留 All/Day/Week/Month 分段，新增 **Custom** 触发器 → popover 浮层（`shadow-md` + `rounded-xl`，全站唯一允许阴影处），内含 From/To 两个 `<input type="date">`；改日期即写 URL（`from`/`to` 已存在），无 Apply 按钮；浮层外点/Esc 关闭；375 全宽堆叠；打开时 `autoFocus` From 框；键盘可达。
- **有界优先**：`min=data.from`、`max=data.to`（2026-08-01~08-30），未来日期不可达，无数据区间不可输入。
- **护栏三则**：① 钳制数据域；② 自定义区间 <7 天 → 趋势区显「Too few samples」，不画线也不画日值点（毛刺）；③ 周期 delta 一律沿用「任一半程 n<8 → Too few samples」，自定义区间不例外。
- **状态表**：无 from/to → All 高亮；命中预设 → 该预设高亮（按 from/to **精确匹配**）；其余 → Custom 激活，触发器显示 `Aug 12 – Aug 21`；from>to → 行内提示「Start is after end」，URL 保持上次有效值。
- **零新色**：浮层用现有 `surface-card`/`line`/`shadow-md`/`line-strong`/`brand` 焦点环。

### 1.1 · 页面布局重排（追加拍板）

- 标题行（h1 + 副标题）独占一行，不再承载任何控件。
- **第一行 = 视图 Tab**（Data | AI Insights），左对齐；第二行 = **筛选空间**（Range 快捷段 + Custom + Platform + Topic + Intent + Clear all），整行在标题下。
- 375 下 Tab 行全宽分段、筛选行纵向堆叠；1024+ 筛选行横向铺开。
- 理由：视图与筛选是两种「全局状态」，分层放置降低认知负担；筛选行获得全宽后可容纳 6 段 Range + Custom 浮层入口。

## 2 · 需求 2：科技感（P1 · 签名动作 + 三处点缀）

- **签名动作 = 趋势信号台**：趋势卡整块改**深墨信号台**（`#0F172A` 底 + 细网格纹理纯 CSS gradient）+ 青色滚动线 + 右上「● LIVE · **as of Aug 30**」数据截止戳（**不是**伪实时轮询）。
- **信号线取舍**：恢复**青线 `#22D3EE`**（青=时间信号，9.88 对比度，3px 全站唯一粗线）；v2 的靛系提亮 `#818CF8` 降为 **Plan B**（走查若青/teal 糊掉即触发，不删）。
- **语义分工**（06 §3.3/E3 增补例外）：靛=状态/推荐（不动），青=时间信号，暗=监测台；「视图分离」保证青与意图 teal **永不共存同一坐标轴**（Intent 视图不叠 Overall 主线）。
- **Token 计划（只增不改）**：加 `signal` `#0891B2`（亮底图形 3.68）/ `signal-ink` `#0E7490`（5.36）/ `signal-on-dark` `#22D3EE`（暗台 9.88）；材质 token `surface-console`（复用 `ink.DEFAULT`）/ `ink-inverse` `#F1F5F9` / `ink-on-console` `#94A3B8` / `line-console` `#1E293B`；`chartTheme.ts` 增 `geoConsole` 暗底变体。06 已拍板色值零改动。
- **三处点缀（P2）**：① tabular-nums + KPI 变化轻量滚动；② 页面底纹/卡片描边微升级（纯 CSS）；③ 加载/聚焦微光。
- **验收红线**：不新增色彩语义（青=时间的增量语义需 E3 例外落地）、不改矩阵五态编码、任何改动对比度不低于现值。

## 3 · 需求 3：多维趋势细分（P0 · 归因形态）

- **裁定**：驳回「多维度×日粒度多线细分」（数据不支持）；采纳「**半程×单维归因**」+ 有限窗口线。
- **窗口口径（唯一合法线，7/14 日窗口内 n≥8 才画线）**：

| 维度 | 总行数 | 半程 n | 裁决 |
|---|---|---|---|
| Overall | 120 | 60 | 7 日滚动线保留（n=28，青 3px 唯一粗线） |
| 意图 A | 60 | 30 | **7 日线（P0，n=14，teal 2px）** |
| 意图 C | 45 | 22.5 | **7 日线（P0，n≈10.5，teal 2px）** |
| 意图 B | 15 | 7.5 | 隐藏不画线；Table 视图保留全量静态值标「insufficient for trend」 |
| 意图 S | 0 | 0 | 置灰 + 脚注「S has no monitored questions」 |
| 平台×5 | 各 24 | 12 | **14 日窗口小多图（P1，n≈11，tooltip「14-day: 11 rows」）** |
| Topic×8 | 各 15 | 7.5 | 时间细分**不做**；静态对比卡 + 口径脚注「Topic 每 2 天 1 题，30 天窗口不足以下时间结论」 |

- **形态**：趋势卡内 `By: Overall | Attribution` 切换。Attribution = 半程 delta 排行表（平台/意图两维，列=前半 n·率 / 后半 n·率 / delta / 判定 signal|error|too few）+ 前半 vs 后半 100% 堆叠占比迁移图（分布漂移，回答「跌在哪」）。
- **排行 → 列表出口（追加拍板）**：归因表每行带 **View questions** 链接 → `/dashboard/questions?<该维度值>`（如 `platform=ChatGPT` / `intent=A`），自动携带当前 from/to 与其余全局筛选（`useGlobalFilter.buildHref`）；意图档另附 **A/C 7 日细分线**（P0）。
- **信号判定**：变化 ≥ 一整行观测影响（平台 1/12 ≈ ±8pt、意图 A 1/30 ≈ ±3.3pt），阈值随分母走；n 徽标一律窗口/半程样本数，**禁全量 n**。
- **抗噪**：断点 `null` 不连线（`connectNulls:false` 现有）；<7 天不画线；样本不足不造线（数据真话）。

## 5 · 落码注意事项（苏姐终审 §4，交老架）

1. n 徽标/归因表一律窗口或半程 n，禁全量 n。
2. 数据截止戳 tooltip 文案随卡出，防答辩追问。
3. v3 §5 撤回清单与定稿同步进最终方案，防旧稿混入（本文件即最终方案，已含）。
4. 3px 是「全站唯一粗线」全局约定——平台小多图不得出现第二根 3px 线，防信号语义稀释。
5. 实现顺序建议：P0 两项 → 一屏 HTML 样片走查（重点=Intent/Overall 视图同屏对比 + 暗台对比度）→ P1 信号台与小多图 → 走查后补 `craft-notes.md`。

## 6 · 答辩话术（苏姐三句）

- 「靛=品牌状态、青=时间信号、暗=监测台，三个语义分工不抢——青与意图 teal 靠视图分离，不靠色相。」
- 「细分不是炫技：窗口 n≥8 才画线，Topic 每 2 天 1 题不达标，所以只留静态对比加口径脚注。」
- 「B/S 隐藏不是缺功能，是数据真话——样本不足不造线，这比硬画八条线更能证明判断。」
