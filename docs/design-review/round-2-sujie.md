## 1 · 需求 3：多维趋势细分（形态裁决）

**抗噪门槛核实表**（窗口 n 为稳定态实测，含预热段即不符合项）：

| 维度 | 总量/天 | 7 日窗口 n | 14 日窗口 n | n≥8 门槛 | 裁决 |
|---|---|---|---|---|---|
| Intent A | 60 / 2·日 | 14 | 28 | ✓ | 接：画线 |
| Intent C | 45 / 1.5·日 | ≈10.5 | ≈21 | ✓ | 接：画线 |
| Intent B | 15 / 每2天1 | ≈4 | 7 | ✗ | 隐藏不画线 |
| Intent S | 0 | 0 | 0 | ✗ | 置灰+脚注 |
| Platform | 23-25 / 0.8·日 | ≈5.6 | ≈11 | ✓（14日） | 接一半：只许 14 日窗口 |
| Topic | 15 / 0.5·日 | 4 | 7 | ✗ | 驳回：时间细分不做 |

- **接**：Intent A/C 7 日线（n≥8 达标，真需求）；S 置灰+脚注（数据真话，同意）。
- **接一半**：Platform 小多图——14 日窗口 n≈11 达标，但 0.8 题/日达不到她自己「平均≥1题/日」的说法，门槛必须重写（见修改要求 1）。
- **驳回**：Topic 小多图。她自己的规则②（窗口<8 不画线）下 Topic 8 格全部 n=7 全灭，草图却画了 7 格线且标 n=15（那是全量 n，不是窗口 n）——**规则与草图自相矛盾**，这版不能进。Topic 保持现有静态对比卡，加一行口径脚注「Topic 每 2 天 1 题，30 天窗口不足以下时间结论」。
- **B/S 处理**：**隐藏，不合并**。A/B/C 是漏斗层级，合并污染口径，答辩一句「为什么 B 并进 A」就露馅；B 在 Table 视图保留全量静态数值，标注「insufficient for trend」。

## 2 · 需求 2：signal 信号族 + 深墨信号台（红线与优先级）

- **是否越过红线：没有**。红线拆三件事，她全满足——已拍板色值零改动（只增 token 不改值）；五态/意图/severity 编码不动（全部引用现有 token）；对比度实算达标（亮底≥3、暗台文字≥6.96）。「青=时间信号」是语义分工的**增量**（正好解决她诊断③「权=不分」），不是推翻；同意给 E3 补一句例外：「靛=状态/推荐，青=时间信号，并存，v1.1 走查验证」。
- **作为评分项：加分，但有两处风险**。加分点：这是签名动作 + 失败态预案，答辩讲得出「为什么只有这一块暗、青色为什么代表时间」就是产品判断的证据，比「换了个色」高一档。风险一：**LIVE 点伪实时**——数据是静态 30 天，答辩被问「LIVE 是轮询还是静态」会露馅；风险二：意图三线（teal 族）与 signal 主线（cyan）同族撞色，青=时间的语义在 Intent 视图里糊掉。
- **最终优先级：从我的 P2 升为 P1，不接受 P0**。理由：信号台是需求 3 Intent 线的宿主，随 P0 一起落码，不再是纯装饰；但它不阻塞核心闭环，P0 位置让给「翻案必做」的自定义区间与 Intent 细分。整页科技感铺陈维持 P2 不做。

## 3 · 需求 1：自定义时间范围（交互形态）

- **接**：popover + 有界 date input（零新色、改日期即写 URL、无 Apply）。与我的护栏一致：`min=data.from`/`max=data.to` 让无数据区间不可达；<7 天不画滚动线沿用现有逻辑；375 全宽堆叠没问题。
- **补三处**：① 状态表漏了 delta 行为——自定义区间下周期 delta 仍按「任一半程 n<8 显示 Too few samples」，不例外；② 预设高亮按 from/to 精确匹配（不要模糊命中）；③ 浮层打开聚焦 From 框，键盘可达。
- **拍板点 3 答案**：选 popover（接，零新色），不选「Last N days + 数字框」——后者凭空多 2 个 token 且交互更重，无收益。

## 5 · 给茜茜的修改要求（修订时逐条回应）

1. 重写抗噪规则①：删「平均≥1题/日」，统一为「7/14 日窗口内 n≥8 才画线」；平台 0.8 题/日、Topic 0.5 题/日的事实与门槛要一致。
2. 撤销 Topic 小多图：草图 7 格有线与规则②矛盾；改静态对比卡 + 一行口径脚注。
3. B/S 统一置灰不画线（B 的 7d n≈4、14d n=7 均不达标）；不合并漏斗层级；B 在 Table 保留全量数值标「insufficient for trend」。
4. n 徽标改窗口样本数（如 n≈11），不是全量 n=15/24；tooltip 写「14-day: 11 rows」。
5. 信号台：同意暗块+青线；LIVE 点改「● LIVE · as of Aug 30」或 tooltip 标注数据截止日。
6. 意图三线（A/B/C teal）与 signal 主线（cyan）在同一暗台的区分度校验；若混淆，用线宽+图例双编码，不靠色相。
7. 自定义区间状态表补 delta 行：任一半程 n<8 → 「Too few samples」；预设高亮按 from/to 精确匹配。
8. 浮层交互自查：打开聚焦 From、Esc/外点关闭（已有）、375 全宽堆叠（已有）。
